Cell 5 — Membersihkan Harga Satuan & Biaya Kirim

Python · Cell 5 — Regex & Currency Converter
# Fungsi pembersih harga
def clean_currency(val):
    if pd.isna(val) or val == '': return np.nan
    s = str(val).replace('Rp', '').replace(' ', '').strip().replace('.', '').replace(',', '')
    try: return float(s)
    except: return np.nan

df['price'] = df['price_raw'].apply(clean_currency)

# Penanganan harga typo (misal salah ketik nol berlebih > Rp 500.000)
df.loc[df['price'] > 500000, 'price'] = df.loc[df['price'] > 500000, 'price'] / 100

# Imputasi harga kosong dengan median harga produk yang sama di katalog
df['price'] = df.groupby('product_name')['price'].transform(lambda x: x.fillna(x.median()))

# Fungsi pembersih ongkir (GRATIS/FREE → 0)
def clean_ship(val):
    if pd.isna(val) or val == '' or str(val).upper() in ['GRATIS', 'FREE', '0']: return 0.0
    s = str(val).replace('Rp', '').replace(' ', '').replace('.', '').replace(',', '').strip()
    try: return min(float(s), 50000.0) # Capping ongkir wajar maks 50k
    except: return 0.0

df['shipping_cost'] = df['shipping_cost_raw'].apply(clean_ship)

print(df[['price', 'shipping_cost']].describe().round(2))

Deteksi & Penanganan Outlier Kuantitas (Metode IQR)
⏱ ~12 menit

Mari kita deteksi apakah ada kuantitas beli yang bernilai anomali (negatif, nol, atau angka ekstrim 99) menggunakan prinsip statistik IQR.

Cell 7 — Perhitungan Kuartil & Batas IQR

Python · Cell 7 — Formula IQR
df['quantity'] = pd.to_numeric(df['quantity'], errors='coerce')

Q1 = df['quantity'].quantile(0.25)
Q3 = df['quantity'].quantile(0.75)
IQR = Q3 - Q1
lower_bound = max(1, Q1 - 1.5 * IQR) # Minimal pembelian retail adalah 1
upper_bound = Q3 + 1.5 * IQR

print(f"Q1: {Q1}, Q3: {Q3}, IQR: {IQR}")
print(f"Batas Wajar Kuantitas Retail: {lower_bound} s/d {upper_bound}")

# Cek baris anomali
anomali_qty = df[(df['quantity'] < lower_bound) | (df['quantity'] > upper_bound)]
print(f"\nJumlah Anomali Kuantitas: {len(anomali_qty)}")
print(anomali_qty[['order_id', 'product_name', 'quantity']])

Cell 8 — Winsorization & Koreksi Kuantitas

Python · Cell 8 — Koreksi Outlier
# 1. Nilai <= 0 dikoreksi menjadi 1 (asumsi minimal beli 1)
df.loc[df['quantity'] <= 0, 'quantity'] = 1

# 2. Outlier ekstrim (> 20) diganti dengan median kuantitas
df.loc[df['quantity'] > 20, 'quantity'] = df['quantity'].median()

print("Statistik Kuantitas Bersih:")

Cell 9 — Imputasi Rating & Status Transaksi

Python · Cell 9 — Imputasi & Standardisasi Pembayaran
# 1. Filter rating invalid (misal 6 atau -1)
df['customer_rating'] = pd.to_numeric(df['customer_rating'], errors='coerce')
df.loc[(df['customer_rating'] < 1) | (df['customer_rating'] > 5), 'customer_rating'] = np.nan

# 2. Imputasi rating per kategori produk
df['customer_rating'] = df.groupby('product_category')['customer_rating'].transform(
    lambda x: x.fillna(x.median())
).round(1)

# 3. Standardisasi metode pembayaran
pay_clean = {'qris': 'QRIS', 'QRIS Barcode': 'QRIS', 'Transfer Bank': 'Transfer Bank Syariah'}
df['payment_method'] = df['payment_method'].fillna('Transfer Bank Syariah').str.strip().replace(pay_clean)

# 4. Status pesanan & Customer ID
df['order_status'] = df['order_status'].fillna('Processing').str.strip().str.title()
df['customer_id'] = df['customer_id'].fillna('CUST-UNKNOWN')
