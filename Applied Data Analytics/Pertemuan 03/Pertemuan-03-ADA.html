Strategi Handling Missing Values
C3.2

Ketika menemukan data hilang (NaN/None), jangan langsung sembarangan menghapus baris (dropna())! Menghapus baris secara serampangan akan menghilangkan informasi penting dan menimbulkan seleksi bias.

Situasi Data HilangStrategi yang TepatContoh Kode
Data hilang > 60% dan tidak krusialDrop kolomdf.drop(columns=['kolom_rusak'])
Baris duplikat atau ID esensial hilangDrop barisdf.dropna(subset=['order_id'])
Numerik berdistribusi normal (simetris)Imputasi Meandf['kolom'].fillna(df['kolom'].mean())
Numerik ada outlier / miring (skewed)Imputasi Mediandf['kolom'].fillna(df['kolom'].median())
Kategorikal (metode bayar / status)Imputasi Modus / Nilai Defaultdf['status'].fillna('Processing')
Karakteristik spesifik per segmenImputasi Berbasis Grupdf.groupby('kat')['rating'].transform('median')

Kode Imputasi Cerdas Berbasis Grup

Python · Imputasi Median per Kategori Produk
# Imputasi rating kosong menggunakan MEDIAN kategori produknya
# Contoh: Rating kosong untuk Kosmetik diisi median rating Kosmetik, bukan global
df['customer_rating'] = pd.to_numeric(df['customer_rating'], errors='coerce')

# Filter rating di luar rentang sah (1-5) menjadi NaN dulu
df.loc[(df['customer_rating'] < 1) | (df['customer_rating'] > 5), 'customer_rating'] = np.nan

# Imputasi berbasis grup
df['customer_rating'] = df.groupby('product_category')['customer_rating'].transform(
    lambda grp: grp.fillna(grp.median())
)

print(f"Sisa null rating: {df['customer_rating'].isna().sum()}")
💡 Mengapa Median Lebih Aman dari Mean? Jika suatu kategori memiliki rating [5, 5, 4, 5, 1], mean-nya adalah 4.0 (tertarik ke bawah oleh angka 1), sedangkan median adalah 5.0. Median adalah ukuran pemusatan data yang tangguh (robust) terhadap nilai ekstrem.

Deteksi & Penanganan Outlier (IQR & Z-Score)
C3.3

Outlier adalah nilai pengamatan yang menyimpang secara drastis dari keseluruhan data. Outlier bisa berupa kesalahan input manusia (misal kuantitas beli tertulis 999 bukannya 9), atau anomali bisnis nyata (misal pembelian borongan B2B).

Metode Interquartile Range (IQR)

Metode IQR tidak mengasumsikan data harus berdistribusi normal. Data dibagi menjadi 4 kuartil: Q1 (persentil 25), Q2 (median), dan Q3 (persentil 75).

📐 Rumus Batas IQR

1.IQR = Q3 - Q1
2.Batas Bawah = Q1 - (1.5 × IQR)
3.Batas Atas = Q3 + (1.5 × IQR)
4.Nilai di luar rentang ini diklasifikasikan sebagai Outlier

🛡️ Strategi Penanganan Outlier

A.Trimming (Drop): Hapus baris jika dipastikan kesalahan sistemik
B.Capping (Winsorization): Batasi nilai ekstrem ke batas bawah / batas atas maksimum yang wajar
C.Imputasi: Ganti dengan median produk sejenis jika terbukti salah ketik
Python · Deteksi Outlier dengan IQR Method
# Deteksi outlier pada kolom kuantitas
df['quantity'] = pd.to_numeric(df['quantity'], errors='coerce')

Q1 = df['quantity'].quantile(0.25)
Q3 = df['quantity'].quantile(0.75)
IQR = Q3 - Q1
lower_bound = Q1 - 1.5 * IQR
upper_bound = Q3 + 1.5 * IQR

outliers = df[(df['quantity'] < lower_bound) | (df['quantity'] > upper_bound)]
print(f"Batas Bawah: {lower_bound:.2f}, Batas Atas: {upper_bound:.2f}")
print(f"Ditemukan {len(outliers)} baris outlier kuantitas:")
print(outliers[['order_id', 'product_name', 'quantity']])

# Penanganan: Capping (Winsorization) nilai ekstrem ke nilai yang valid
df.loc[df['quantity'] <= 0, 'quantity'] = 1                    # Nilai negatif/-1/0 di-set 1
df.loc[df['quantity'] > upper_bound, 'quantity'] = upper_bound  # Capping nilai ekstrim

Konversi Tipe Data & Operasi Teks (String Cleaning)
C3.4, C3.5

Seringkali data teks memiliki inkonsistensi penulisan: ada spasi di awal/akhir (leading/trailing whitespace), kombinasi huruf besar-kecil tidak seragam, atau singkatan berbeda untuk entitas yang sama (misal 'JKT Selatan', 'jak-sel', dan 'Jakarta Selatan').

Pembersihan Teks Terstruktur

Python · Pembersihan String & Standardisasi Kamus
# 1. Menghapus spasi liar & kapitalisasi rapi nama customer
df['customer_name'] = df['customer_name'].str.strip().str.title()

# 2. Standardisasi Nama Kota menggunakan Dictionary Mapping
city_map = {
    'JKT Selatan': 'Jakarta Selatan', 'jak-sel': 'Jakarta Selatan',
    'JKT TIMUR': 'Jakarta Timur',     'bdg': 'Bandung',
    'BANDUNG': 'Bandung',             'BOGOR': 'Bogor',
    'bogor': 'Bogor',                 'DEPOK': 'Depok',
    'Tangsel': 'Tangerang Selatan',   'SBY': 'Surabaya',
    'surabaya': 'Surabaya',           'Jogja': 'Yogyakarta',
    'YOGYA': 'Yogyakarta'
}
df['customer_city'] = df['customer_city'].str.strip().replace(city_map)

# 3. Membersihkan String Angka dengan regex & konversi ke Float
def clean_currency(val):
    if pd.isna(val) or val == '': return np.nan
    s = str(val).replace('Rp', '').replace(' ', '').strip()
    s = s.replace('.', '').replace(',', '')
    try:
        return float(s)
    except:
        return np.nan

df['price'] = df['price_raw'].apply(clean_currency)

# 4. Parsing Tanggal Aman dengan errors='coerce'
df['order_date'] = pd.to_datetime(df['order_date'], format='mixed', errors='coerce')
💡 Parameter errors='coerce' pada pd.to_datetime: Jika ada format tanggal yang cacat (seperti 'INVALID_DATE' atau '99/99/2026'), pandas tidak akan memunculkan program error yang menghentikan eksekusi, melainkan mengubah nilai rusak tersebut menjadi NaT (Not a Time) sehingga mudah kita saring atau imputasi.

إِنَّ اللَّهَ يُحِبُّ التَّوَّابِينَ وَيُحِبُّ الْمُتَطَهِّرِينَ

2. Menghindari Gharar (Ketidakpastian & Penipuan)
نَهَى رَسُولُ اللَّهِ صَلَّى اللَّهُ عَلَيْهِ وَسَلَّمَ عَنْ بَيْعِ الْغَرَرِ
