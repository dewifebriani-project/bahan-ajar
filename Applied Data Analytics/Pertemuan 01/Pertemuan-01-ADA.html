ADA dalam Ekosistem Data Science
C2.1

Pipeline Data Science — Di Mana ADA Berada?

Data science bukan satu pekerjaan — ia adalah pipeline dari data mentah hingga keputusan bisnis. Setiap tahap membutuhkan kemampuan berbeda, dan dua matakuliah kamu semester ini masing-masing menguasai satu layer penting.

Insight Kunci: ADA adalah "otak" — menganalisis dan menemukan insight. BIV adalah "wajah" — mengkomunikasikan insight kepada pengambil keputusan. Kamu butuh keduanya untuk menjadi data analyst yang lengkap.

Contoh Konkrit — BPRS Berkah Syariah Bogor

BPRS Berkah Syariah memiliki data 890 nasabah dan ribuan transaksi pembiayaan. Tim mereka perlu menjawab: "Nasabah jenis apa yang paling sering gagal bayar (NPF tinggi)? Bagaimana kita bisa prediksi lebih awal?"

  • Layer ADA: Tim analis mengimpor data transaksi dengan pandas, membersihkan data (hapus duplikat, isi nilai kosong), membuat model klasifikasi dengan scikit-learn — menghasilkan daftar nasabah berisiko tinggi.
  • Layer BIV: Tim BI memvisualisasikan hasil di Power BI — dashboard NPF per cabang, tren bulanan, heatmap risiko — sehingga direktur bisa langsung melihat dan memutuskan.

Dari RapidMiner ke Python — Kenapa?
C2.2

Semester lalu kamu belajar konsep analitik data dengan RapidMiner. Itu fondasi yang baik. Sekarang kita naik level — bukan karena RapidMiner buruk, tapi karena Python membuka pintu yang tidak bisa dibuka RapidMiner.

🟡 RapidMiner (sebelumnya)

🖱️Visual drag-and-drop — nyaman untuk belajar konsep
🔒Proprietary/berbayar — akses terbatas di luar kampus
📦Operator bawaan — kurang fleksibel untuk kasus khusus
📊Cocok untuk: prototyping, belajar algoritma visual
🏭Jarang dipakai di industri data Indonesia skala startup/enterprise

🟦 Python (sekarang)

⌨️Berbasis kode — kontrol penuh atas setiap langkah analisis
🆓Open source, gratis selamanya, komunitas global terbesar
♾️Ribuan library — tidak ada batasan kemampuan
🚀Bisa deploy: buat app analytics, API, laporan otomatis
💼Standar industri data science global dan Indonesia
Insight Penting: Kamu TIDAK memulai dari nol. Di RapidMiner, kamu sudah belajar konsep EDA, klasifikasi, regresi, clustering. Di Python, kamu tinggal MENGIMPLEMENTASIKAN konsep yang sama dengan kode — hasilnya bisa dikustomisasi, di-deploy, dan diintegrasikan ke sistem nyata.

Yang sudah kamu miliki vs yang akan kita tambah

  • ✅ Sudah punya: Memahami konsep EDA (distribusi, outlier, korelasi)
  • ✅ Sudah punya: Tahu perbedaan supervised vs unsupervised learning
  • ✅ Sudah punya: Bisa interpretasi confusion matrix, precision, recall
  • 🆕 Akan ditambah: Implementasi kode Python — pandas, sklearn, numpy
  • 🆕 Akan ditambah: Membangun pipeline analitik dari nol dan mendeploy sebagai app
  • 🆕 Akan ditambah: Menangani dataset besar (10–50 juta baris) dengan DuckDB

6 Library Inti yang Akan Kita Pelajari
C2.3

Ekosistem Python untuk data science sangat luas. Semester ini kita fokus pada 6 library inti yang membentuk pipeline analitik dari data mentah hingga aplikasi yang bisa digunakan.

🐼
pandas
Manipulasi data tabular — load, clean, filter, group, transform. "Spreadsheet versi Python" yang ribuan kali lebih kuat.
P1–P11 (inti)
🔢
numpy
Komputasi numerik dan array multidimensi. Fondasi matematis hampir semua library data science Python.
P1–P11 (fondasi)
📉
matplotlib / seaborn
Visualisasi statis — grafik, histogram, scatter plot. BIV akan lebih dalam, tapi kita pakai ini untuk EDA cepat.
P2–P8 (EDA)
🤖
scikit-learn
Machine learning pipeline lengkap — preprocessing, train/test split, model (classification, regression, clustering), evaluation.
P7–P11
🌐
Streamlit
Build web app analytics dengan Python murni — tanpa HTML/CSS. Deploy ke cloud gratis. Output utama UAS ADA.
P12–P14
🦆
DuckDB
SQL analytics pada file CSV/Parquet besar (jutaan baris) langsung di Colab — tanpa server database.
P15
⚠️ Jangan panik! Kamu tidak harus menguasai semua sekarang. Kita belajar satu per satu, mulai dari pandas dan numpy sebagai fondasi. Setiap library diperkenalkan tepat saat kita butuh — bukan dijejalkan sekaligus.

Google Colab — Lingkungan Kerja Kita
C2.4

Google Colaboratory (Colab) adalah notebook Python berbasis cloud yang berjalan di browser. Tidak perlu instalasi apapun — buka browser, kode, selesai.

Kenapa Colab (dan bukan install Python lokal)?

  • Zero setup: Tidak perlu install Python, pip, atau library apapun — semuanya sudah tersedia
  • Cloud-based: Kode kamu tersimpan di Google Drive — tidak hilang, bisa diakses dari HP
  • GPU gratis: Untuk model ML yang berat, bisa pakai GPU Tesla T4 secara gratis
  • Kolaborasi: Share notebook seperti Google Docs — cocok untuk kerja kelompok
  • Akses: colab.new atau colab.research.google.com

Nilai Syariah — Amanah & Itqan dalam Analitik
CPL-S2

Analitik data bukan sekadar teknik — ia adalah tanggung jawab moral. Dua nilai Islam ini menjadi panduan etis sepanjang semester ADA.

☾ Amanah — الأمانة
وَلَا تَأْكُلُوٓا۟ أَمْوَٰلَكُم بَيْنَكُم بِٱلْبَـٰطِلِ
"Sesungguhnya Allah menyuruh kamu menyampaikan amanah kepada yang berhak menerimanya." (QS. An-Nisa: 58)

Dalam ADA: Data nasabah BPRS, data transaksi keuangan, data kesehatan pelanggan — semuanya adalah amanah. Analis data wajib menjaga kerahasiaan, tidak menyalahgunakan, dan menganalisis dengan jujur tanpa cherry-pick.

QS. An-Nisa: 58 | QS. Al-Baqarah: 282
☾ Itqan — الإتقان
إِنَّ اللَّهَ يُحِبُّ إِذَا عَمِلَ أَحَدُكُمْ عَمَلاً أَنْ يُتْقِنَهُ
"Sesungguhnya Allah mencintai jika seseorang di antara kalian melakukan sebuah pekerjaan, maka ia melakukannya dengan itqan (sempurna/tuntas)." (HR. Baihaqi)

Dalam ADA: Kode yang ditulis asal-asalan, analisis yang tidak divalidasi, insight yang disampaikan tanpa verifikasi — bukan itqan. Tulis kode yang bersih, beri komentar, dan validasi selalu sebelum menyimpulkan.

HR. Baihaqi · Mu'jam Al-Awsath, Thabarani
Aplikasi Praktis P01: Ketika kamu me-load dataset BPRS di praktikum nanti — ingat bahwa data nasabah yang kamu analisis adalah amanah. Gunakan data simulasi (bukan data nyata) untuk belajar. Di dunia kerja nyata, wajib mengikuti kebijakan privasi data dan tidak menyebarkan data klien.
