Deskripsi & Visi Matakuliah

Applied Data Analytics (ADA) adalah matakuliah lanjutan yang membekali mahasiswa dengan kemampuan praktis menggunakan Python sebagai alat utama analisis data bisnis. Berbeda dari Pengantar Data Analytics yang menggunakan RapidMiner (visual/no-code), ADA membuka "kotak hitam" tersebut — mahasiswa memahami dan mengendalikan setiap langkah proses analitik.

Visi akhir: mahasiswa mampu membangun aplikasi analitik yang dapat digunakan orang lain — bukan hanya notebook yang bisa dijalankan sendiri.

Mahasiswa sudah tahu apa: Konsep EDA, preprocessing, klasifikasi/regresi dasar, cross-validation — lewat RapidMiner. ADA membangun di atas pondasi itu, bukan mengulang dari awal.
🛠️
Tech Stack
  • Environment: Google Colab (gratis, zero setup) → Jupyter Notebook lokal untuk project akhir
  • Wrangling: pandas, numpy — standar industri, ekosistem terlengkap
  • Visualisasi Analisis: matplotlib, seaborn (eksplorasi) + Plotly Express (interaktif)
  • ML Pipeline: scikit-learn (preprocessing, model, evaluasi) — library ML paling banyak dipakai dunia kerja
  • App Deployment: Streamlit — Python murni, jadi web app dalam 10 menit, gratis deploy ke Streamlit Community Cloud
  • Large Data: DuckDB (SQL pada file CSV/Parquet tanpa database server) + polars (pandas 10–50× lebih cepat untuk file besar)
  • Dataset: Kaggle Datasets — tersedia ratusan dataset bisnis 1–10 juta baris secara gratis
Sinergi dengan BIV: Pada P13, mahasiswa mengekspor hasil analisis Python (dataset bersih + insight) ke format yang langsung bisa dibuka di Power BI. Satu dataset, dua matkul, satu cerita.
🗂️
Empat Fase Pembelajaran
  • Fase 1 — Bridge (P1–4): Transisi dari RapidMiner ke Python. Mahasiswa mengulang workflow EDA yang sudah dikenal tapi kali ini dengan kode, bukan klik.
  • Fase 2 — Analytics Core (P5–9): EDA mendalam, feature engineering, ML pipeline yang benar, interpretasi bisnis. UTS = mini project EDA + simple model.
  • Fase 3 — Build & Scale (P10–14): Clustering, time series, Streamlit app, kerja efisien dengan data besar menggunakan DuckDB dan polars.
  • Fase 4 — Capstone (P15–16): Workshop + Demo Day. Setiap kelompok mendemokan analytics app mereka kepada kelas.

Mini Project UTS — EDA + Simple Model
P9 · Kelompok 3–4 orang · Presentasi 10 menit
Deliverable: Colab Notebook (.ipynb) + Slide presentasi (maks 10 slide) + demo live notebook
Konten minimal: (1) Latar belakang dataset & pertanyaan bisnis; (2) EDA lengkap dengan insight bermakna; (3) Minimal 1 model klasifikasi atau regresi; (4) Evaluasi model dengan metrik yang tepat; (5) Rekomendasi bisnis berbasis hasil analisis; (6) Relevansi dengan nilai Islami
Dataset pilihan: Wajib dari Kaggle, minimal 5.000 baris, relevan dengan bisnis/keuangan/ekonomi Islam (e-commerce, UMKM, keuangan syariah, pertanian, kesehatan)
2
Analytics App (UAS) — Streamlit Application
P16 Demo Day · Kelompok 3–4 orang · Demo 15 menit
Deliverable: (1) Link Streamlit app yang sudah deployed; (2) GitHub repository dengan kode lengkap; (3) README.md yang menjelaskan cara penggunaan; (4) Laporan singkat 3–5 halaman
Fitur minimum app: Upload/load dataset → tampil ringkasan statistik → minimal 3 visualisasi interaktif → minimal 1 model prediksi dengan input form → halaman "About / Interpretasi" yang menjelaskan insight bisnis
Contoh topik yang disarankan: Prediksi risiko pembiayaan syariah · Segmentasi nasabah koperasi · Forecasting demand UMKM halal · Analisis sentimen ulasan produk halal · Deteksi anomali transaksi keuangan
Nilai Syariah dalam Proyek: Setiap kelompok wajib merefleksikan bagaimana analisis mereka berkontribusi pada maslahah (kemaslahatan umum) dan bagaimana mereka menjaga amanah dalam menyajikan hasil analisis secara jujur.
