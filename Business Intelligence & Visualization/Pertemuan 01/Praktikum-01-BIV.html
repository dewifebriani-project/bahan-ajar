1
Download & Install Power BI Desktop
⏱ ~5 menit

Power BI Desktop adalah aplikasi gratis dari Microsoft untuk membuat laporan dan dashboard BI. Tidak perlu akun berbayar — versi Desktop sepenuhnya gratis dan cukup untuk seluruh semester ini.

Halaman download Power BI Desktop di powerbi.microsoft.com

📋 Langkah-langkah Download & Install

  1. 1Buka browser dan kunjungi powerbi.microsoft.com/desktop (atau cari "Power BI Desktop download" di Google)
  2. 2Klik tombol "Download Free" atau "Download gratis" — file installer ~500 MB akan terunduh
  3. 3Alternatif lebih cepat: cari "Power BI Desktop" di Microsoft Store pada PC kamu — install langsung dari sana
  4. 4Jalankan installer (.exe) dan ikuti panduan instalasi — Next → Next → Install. Tidak perlu akun Microsoft untuk instalasi awal.
  5. 5Setelah install selesai, buka Power BI Desktop. Kamu akan diminta login — gunakan akun Microsoft organisasi (jika tersedia) atau buat akun gratis di app.powerbi.com dengan email kampus.
⚠️ Mac/Linux Users: Power BI Desktop hanya tersedia untuk Windows. Opsi: (1) gunakan Power BI Service di browser lewat app.powerbi.com — fitur laporan tersedia terbatas; (2) pinjam laptop Windows di lab; (3) gunakan Windows via Parallels (Mac) atau VM. Diskusikan dengan dosen untuk solusi terbaik.
💡 Sudah punya Power BI? Pastikan versinya minimal Oktober 2023 ke atas. Buka Help → About untuk cek versi. Update tersedia gratis di Microsoft Store.
Klik setelah Power BI berhasil dibuka

Kenali Antarmuka Power BI Desktop
⏱ ~10 menit

Power BI Desktop memiliki antarmuka yang terstruktur. Sebelum membuat apapun, kamu harus memahami 7 area utama agar tidak tersesat. Luangkan 2 menit untuk menjelajah setiap area.

Antarmuka Power BI Desktop — 7 area utama yang wajib dikenal

7 Area Antarmuka yang Wajib Dikenal

  • ① Ribbon: Toolbar di bagian atas — berisi tombol utama seperti Get Data (konek ke sumber data), Transform Data (buka Power Query), dan New Visual.
  • ② View Selector: 3 ikon di sisi kiri — Report View (membuat dashboard), Data View (melihat tabel data), Model View (melihat relasi antar tabel).
  • ③ Canvas: Area putih di tengah — tempat kamu mendesain dashboard dengan menarik dan menempatkan visual.
  • ④ Page Tabs: Tab halaman di bagian bawah canvas — bisa membuat multi-halaman (Overview, Detail, Story).
  • ⑤ Visualizations Panel: Panel kanan atas — berisi semua tipe chart (bar, line, pie, dll.) dan area untuk meletakkan field (drop zone).
  • ⑥ Fields Panel: Panel kanan bawah — menampilkan semua kolom dari dataset yang sudah diload. Tanda Σ artinya kolom numerik (bisa dijumlahkan).
  • ⑦ Filters Panel: Di antara Visualizations dan Fields — untuk menambahkan filter tingkat visual, halaman, atau report.
💡 Tips: Kalau panel kanan tidak terlihat, buka tab View di Ribbon dan aktifkan Visualizations, Fields, dan Filters dari menu tersebut.

Koneksi Dataset Retail Syariah — Data Pertamamu!
⏱ ~10 menit

Dataset dataset-retailsyariah-p01.csv berisi 60 transaksi penjualan dari 5 minimarket syariah di 5 kota Indonesia, selama Januari–Juni 2026. Kita akan memuatnya ke Power BI menggunakan Get Data.

Dialog "Get Data" di Power BI — pilih Text/CSV untuk file CSV

📋 Langkah Load Dataset ke Power BI

  1. 1Download file dataset-retailsyariah-p01.csv dari folder yang sama dengan file Praktikum ini (Business Intelligence & Visualization)
  2. 2Di Power BI Desktop, klik tab Home di Ribbon, lalu klik Get Data → pilih Text/CSV
  3. 3Dialog file picker akan terbuka — navigasi ke lokasi file CSV yang sudah didownload, pilih filenya, klik Open
  4. 4Power BI akan menampilkan preview data — pastikan kolom sudah terdeteksi dengan benar (tanggal, nama_toko, kategori_produk, total_penjualan, dll.)
  5. 5Klik Load (bukan "Transform Data" dulu) — data langsung masuk ke model Power BI
  6. 6Setelah load selesai, klik ikon Data View (ikon tabel 📋 di sisi kiri) untuk memverifikasi semua 60 baris data sudah masuk

Buat Chart Pertama — Bar Chart Penjualan per Kategori
⏱ ~15 menit

Sekarang data sudah ada di Power BI. Saatnya membuat visualisasi pertama — Clustered Bar Chart yang menampilkan total penjualan per kategori produk. Di Power BI, membuat chart semudah drag-and-drop.

Proses drag-and-drop untuk membuat bar chart di Power BI

📋 Langkah-langkah Membuat Bar Chart

  1. 1Di panel Visualizations (kanan atas), klik ikon Clustered bar chart — ikon yang mirip batang horizontal. Sebuah kotak kosong akan muncul di canvas.
  2. 2Di panel Fields (kanan bawah), temukan kolom kategori_produk. Drag (tahan dan seret) kolom ini ke drop zone Y-axis di Visualizations Panel.
  3. 3Temukan kolom total_penjualan (ada tanda Σ = numerik). Drag ke drop zone X-axis. Power BI otomatis menjumlahkan (SUM) semua nilai per kategori.
  4. 4Bar chart akan langsung muncul dengan 5 kategori. Klik luar visual untuk deselect, lalu resize dengan drag sudutnya agar lebih besar dan jelas.
  5. 5Tambahkan judul: klik visual → di Visualizations Panel klik ikon kuas (Format visual) → General → Title → ketik "Total Penjualan per Kategori Produk"
Bar chart muncul dengan 5 batang kategori: - Makanan & Minuman: nilai tertinggi (~5 juta) - Herbal & Kesehatan: urutan 2 - Pakaian Muslim: urutan 3 - Perawatan Diri: urutan 4 - Perlengkapan Rumah: urutan 5 Setiap batang menunjukkan SUM(total_penjualan) untuk kategori tersebut.
💡 Power BI auto-SUM: Ketika kamu drop field numerik (Σ) ke visual, Power BI otomatis menjumlahkan semua nilai. Ini DAX yang bekerja di belakang layar — kita akan belajar DAX sendiri secara eksplisit di P6.
💡 Sorting: Klik titik tiga (…) di sudut kanan atas chart → Sort by → Sum of total_penjualan → Descending untuk urut dari terbesar ke terkecil.
5
Buat KPI Card & Simpan Report
⏱ ~10 menit

KPI Card adalah visual single-number yang menampilkan metrik kunci dalam satu angka besar — misalnya "Total Penjualan: Rp 17.800.000". Ini adalah visual paling fundamental dalam setiap executive dashboard.

Dashboard sederhana dengan 2 KPI Card + 1 Bar Chart

📋 Langkah-langkah Buat KPI Card

  1. 1Klik area kosong di canvas (pastikan tidak ada visual yang terseleksi). Di panel Visualizations, klik ikon Card (kotak dengan angka besar — biasanya tanda ⬚123 atau label "Card").
  2. 2Drag kolom total_penjualan (Σ) dari Fields Panel ke drop zone Fields di Visualizations. Card akan menampilkan Sum of total_penjualan.
  3. 3Untuk KPI Card kedua: klik area kosong → klik ikon Card lagi → drag kolom id_transaksi ke drop zone. Di drop down aggregation (klik tanda ▾ di sebelah field), pilih Count — ini akan menghitung jumlah transaksi unik.
  4. 4Atur posisi: drag card-card ini ke bagian atas canvas, letakkan sejajar. Resize agar proporsional dengan bar chart di bawahnya.

💾 Simpan Report sebagai .pbix

  1. 1Klik tab File di Ribbon (atau tekan Ctrl + S)
  2. 2Pilih Save As (pertama kali) → pilih lokasi folder → beri nama file: P01_Intro_BIV
  3. 3Klik Save — file akan tersimpan sebagai P01_Intro_BIV.pbix (format native Power BI)
  4. 4Selanjutnya cukup tekan Ctrl + S untuk menyimpan perubahan
Dashboard P01 berisi: ✓ KPI Card 1: Total Penjualan = Rp 17.800.000 (sum semua transaksi) ✓ KPI Card 2: Jumlah Transaksi = 60 (count id_transaksi) ✓ Bar Chart: Total Penjualan per Kategori (5 batang) File tersimpan sebagai: P01_Intro_BIV.pbix

Jika ya, kamu sudah menjalankan prinsip Bayan — menyampaikan informasi dengan jelas kepada yang membutuhkan.
6
Tantangan Mandiri — Eksplorasi Sendiri!
⏱ ~15 menit

Sekarang waktunya bereksperimen sendiri menggunakan dataset yang sama. Tidak ada jawaban yang benar atau salah — tujuannya adalah membangun intuisi tentang bagaimana Power BI bekerja.

🎯 3 Tantangan Visualisasi

Tantangan 1 — Line Chart Tren Bulanan: Tambahkan Line Chart baru di halaman yang sama. Drag tanggal ke X-axis dan total_penjualan ke Y-axis. Power BI mungkin otomatis mengelompokkan per bulan — jika ya, ini sudah benar! Pertanyaan: bulan mana penjualan paling tinggi? Hint: klik tanda ▾ pada field tanggal di X-axis untuk memilih granularitas "Month"
Tantangan 2 — Slicer Filter: Tambahkan visual Slicer (ikon seperti corong ▽). Drag kota ke field slicer. Sekarang klik salah satu kota di slicer — perhatikan bagaimana bar chart dan card otomatis berubah hanya menampilkan data kota tersebut! Ini adalah interaktivitas Power BI yang paling mendasar. Hint: Ctrl+klik untuk pilih beberapa kota sekaligus
Tantangan 3 — Donut Chart Metode Pembayaran: Buat halaman baru (klik + di tab bawah). Tambahkan Donut Chart. Drag metode_pembayaran ke Legend dan total_penjualan ke Values. Pertanyaan: metode pembayaran mana yang menghasilkan total penjualan terbesar? Apakah QRIS lebih populer dari Tunai?
💡 Shortcut Power BI yang Berguna:
Ctrl + Z — Undo (jika visual berantakan)
Ctrl + S — Save (lakukan ini sering!)
Delete — Hapus visual yang terseleksi
F11 — Fullscreen mode untuk presentasi
Ctrl + A — Select all visuals di halaman aktif
☾ Pertanyaan Refleksi Bayan (tulis di notebook atau kertas):

Setelah membuat 3–4 visual dari dataset yang sama, pilih satu insight yang menurutmu paling penting untuk dilaporkan kepada pemilik minimarket syariah. Tulis dalam 2–3 kalimat: (1) Apa insightnya? (2) Mengapa ini penting untuk bisnis? (3) Apa rekomendasi tindakan yang bisa diambil? — Ini adalah latihan awal Data Storytelling yang akan kita pelajari lebih dalam di P8.
💡 Cara membuat halaman baru di Power BI: Klik tanda + di tab bagian bawah canvas. Rename halaman dengan klik kanan → Rename Page. Disarankan beri nama: "Overview" untuk halaman pertama, "Detail" untuk halaman kedua.
